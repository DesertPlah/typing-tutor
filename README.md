# Bisonauts — Relight the Keyboard Galaxy

A kid-safe touch-typing tutor for Paul Sundquist's kids (William, 4th grade; Elijah, 6th grade).

**Theme:** bison pilot + space. The keyboard is a star map that lights up as keys are mastered.

## Play

Open the live GitHub Pages link, or open `index.html` locally (works offline after load; no network calls).

## Profiles

- **Elijah** / **William** — one tap to create, separate progress
- **Parent** — sessions, heatmap, weak keys, backup/restore

## Practice (~12 min)

Pre-flight check → warm-up → optional new key pair → 3 adaptive missions → debrief  
(Warp Sprint speed burst from stage 6+)

## Data

Progress is stored in `localStorage` per profile. Use **Parent → Backup** (JSON download or copy-paste code) so Chromebook wipes don't lose progress.
